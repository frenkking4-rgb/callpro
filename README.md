## Установка и запуск (локально)
Приведён общий пример; подстройте под ваш стек.

1. Клонировать репозиторий:
   git clone https://github.com/frenkking4-rgb/callpro.git
2. Перейти в каталог проекта:
   cd callpro

Если проект статический (только фронтенд):
- Откройте `index.html` в браузере или запустите локальный сервер:
  - Python 3: `python -m http.server 8000` (в корне)
  - затем открыть http://localhost:8000

Если есть бэкенд на Python:
1. Создайте виртуальное окружение:
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   venv\Scripts\activate     # Windows
2. Установите зависимости:
   pip install -r requirements.txt
3. Экспортируйте переменные окружения (пример):
   export FLASK_APP=app.py
   export FLASK_ENV=development
4. Запустите сервер:
   flask run
5. Откройте в браузере http://localhost:5000

(Замените команды в соответствии с реальной структурой проекта.)
